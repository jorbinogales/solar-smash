# Sistema Solar Procedural

Juego espacial multijugador (three.js + Node). Crea una sala, elige planetas y comparte el código.

## Instalar en el PC (Windows)
Descarga `Sistema Solar Procedural Setup 1.0.0.exe` desde [Releases](https://github.com/jorbinogales/solar-smash/releases/latest) y ejecútalo.
La app lleva su propio servidor: para jugar en red local pasa a tus amigos la URL `http://TU-IP:3477`.
Para jugar en un servidor en línea, crea un archivo `servidor.txt` junto al ejecutable con su URL.

## Desarrollo
`npm install && npm start` (web, puerto 3000) · `npm run electron` (app) · `npm run dist` (instalador)
